# Agent UI SDK

Build agent applications with Vue conversation controls that work across harnesses. Compose prompts, stream messages, answer requests, choose models, and embed document previews without building another conversation UI.

Use a complete `ConversationPane`, or compose individual controls. A host supplies session state, capabilities, catalogs and actions. Provider execution belongs in `@korus-dev/multi-agent-sdk`; routing, persistence and application workflows belong in your application.
