# Spark Electron sample

Run `npm run dev:spark -- --backend codex` from the repository root. Backend values are `codex`, `claude`, `cursor` and `antigravity`; Codex is the default.

Configuration, authentication, workspace and Electron data are isolated under `~/.agent-ui-sdk/samples/spark/<backend>/`. Sign in with this sample profile rather than your standard runtime home. See the [sample guide](../../../docs/guide/samples.md).
